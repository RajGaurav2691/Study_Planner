# 📚 Smart Study Planner

A modern full-stack study planner built with Next.js and Prisma.

## 🚀 Live Demo

https://study-planner-pink-phi.vercel.app

---

## ✨ Features

- 🔐 Email & Password Authentication
- 🔑 Google OAuth Login
- 📧 Forgot Password via Email
- 🔄 Password Reset
- 👤 User Registration
- 📱 Responsive UI
- 🗄️ MySQL Database
- ⚡ Prisma ORM
- ☁️ Vercel Deployment
- 🚂 Railway Database

---

## ⚙️ Installation

```bash
git clone https://github.com/RajGaurav2691/Study_Planner.git
cd Study_Planner
npm install
```

Create a `.env` file:

```env
DATABASE_URL=
NEXTAUTH_URL=
NEXTAUTH_SECRET=
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
EMAIL_USER=
EMAIL_PASS=
```

Run:

```bash
npm run dev
```
